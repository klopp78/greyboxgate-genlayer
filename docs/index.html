GreyboxGate

A policy-bound payment gate for AI agents receiving untrusted instructions. An approved receipt can release GEN only through its named executor, fixed recipient, exact amount, and on-chain expiry.

Open deployed contract

1. Consensus receipt

Policies and assessments are created in the full workflow application. Paste an approved action ID here to inspect the resulting on-chain receipt before a wallet can send value.

2. Protected payout

The named executor supplies the exact receipt-bound GEN amount. The contract checks the receipt is approved, unexpired, unused, and still matches the policy, then transfers only to the policy-fixed recipient.

Inspect an action to load its executor, recipient, amount, and expiry.

3. Final record

After consensus finality, the page reads the execution record back from GreyboxGate. A transaction response alone is not displayed as success.
