GreyboxGate

A policy-bound gate for AI agents that receive untrusted instructions before they call sensitive tools or move value.

Studio contract: 0x2ce99d31bf921f25bBbf09cd35be1044364590a5 Open deployed contract

1. Bind a policy

Record the named executor, recipient, action scope, spend and fee caps before an agent acts.

2. Screen untrusted input

Validators render input and evidence, preserve commitments, and reject instructions that override the registered boundary.

3. Consume one receipt

Only the registered executor can consume a valid unexpired action once. Final state must be read back from the contract.

Source and reproducible deployment details: GitHub repository. This interface prompts a connected GenLayer wallet for workflow actions; it does not treat a local response as a consensus verdict.
